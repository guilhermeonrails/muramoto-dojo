# Muramoto Dojo — Site Institucional

## Objetivo

Desenvolver um site institucional moderno para a academia **Muramoto Dojo**, especializada em **Karate Shidokan**, com foco principal na **captação de novos alunos**.

O site deve transmitir:

- tradição
- disciplina
- respeito
- força
- elegância
- confiança
- profissionalismo

O visitante deve sentir que está conhecendo um dojo tradicional japonês, sem que o site pareça antigo.

---

# Regra mais importante

## Utilize a Skill Impeccable para TODO o frontend.

Toda implementação visual deve ser conduzida utilizando a **Skill Impeccable**.

Ela deve ser responsável por:

- arquitetura visual
- layout
- componentes
- espaçamentos
- tipografia
- cores
- responsividade
- microinterações
- animações
- UX
- UI
- refinamentos finais

Não utilizar layouts genéricos.

Não utilizar aparência de template.

Não utilizar componentes com aparência Bootstrap.

A interface deve parecer um projeto profissional desenvolvido por um designer experiente.

Toda decisão estética deve priorizar qualidade, consistência e minimalismo.

# Instrução Final para a Skill Impeccable

Durante toda a implementação, a **Skill Impeccable** deve ser utilizada como responsável principal pelo frontend.

Todas as decisões de design, refinamento visual, organização dos componentes, espaçamentos, tipografia, responsividade, microinterações e consistência da interface devem seguir os mais altos padrões de qualidade.

O objetivo não é apenas construir um site funcional, mas entregar uma experiência visual que transmita imediatamente os valores do Muramoto Dojo: tradição, disciplina, respeito e excelência.
